# 유통기한 이슈 재고리스트 분석기 (Claude Code 버전)

엑셀(Excel) 재고 데이터를 **100% 로컬 브라우저 환경**에서 파싱하고, 유통기한 기준 악성 재고 및 위험 품목을 분석하는 독립형 Next.js 웹 애플리케이션입니다.

기존 Firebase Studio 버전(`../project_유통기한 이슈 재고리스트`)을 Claude Code로 동일하게 재구축한 것입니다. 외부 클라우드 연결 없이 완전히 독립적으로 동작합니다.

## 주요 기능

- **로컬 엑셀 파싱**: 업로드한 엑셀을 서버 전송 없이 브라우저에서 파싱 (FileReader + SheetJS)
- **월별 비교 요약 카드**: 총 재고 금액, 악성 위험 품목 수, 악성 위험 재고 금액 및 증감
- **추이 그래프**: 전월 대비 막대/도넛 차트, 이번달 시트별 연간 추이 라인 차트 (recharts)
- **N개월 내 만기 품목 현황**: 0~12개월 슬라이더, 식품/화장품 분리 표
- **악성 위험 품목 분석**: FIFO 로직 기반 위험 판정 및 행 강조, 검색/필터
- **수동 제외 품목**: 엑셀의 "악성위험 제외 품목코드(시판/방판)" 컬럼 반영
- **위험 상태 변동**: 전월 대비 신규 악성 위험 / 위험 해소 품목
- **채널 필터**: 전체 / 시판 / 방판
- **보고서 내보내기**: PDF(jsPDF + html2canvas, 한글 폰트), 엑셀(다중 시트), 독립 실행형 HTML

## 악성 위험(FIFO) 판정 로직

품목코드별로 모든 로트를 만기일 오름차순 정렬 후:

- 월평균 판매수량 ≤ 0 → 재고가 있으면 위험
- 그 외 → 로트를 누적하며 `누적수량 ÷ 월평균판매수량`(소진 소요 개월)과 해당 로트의 `만기까지 일수 ÷ 30.4375`(만기까지 개월)를 비교. 어느 로트에서든 소진 소요가 만기까지 기간을 초과하면 위험.

## 시작하기

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:9003` 접속 후 전월/금월 재고 엑셀 파일을 업로드하세요.

`품목코드`, `품목이름`, `총수량`, `만기일(최소)`, `창고명`, `월평균 판매수량`, `구매단가`, `시판/방판`,
`악성위험 제외 품목코드(시판)`, `악성위험 제외 품목이름(시판)`, `악성위험 제외 품목코드(방판)`, `악성위험 제외 품목이름(방판)`
